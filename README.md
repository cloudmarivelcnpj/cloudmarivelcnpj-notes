# cloudmarivelcnpj-notes

Compilers · Next.js · Networking · Developer Tools

折腾中的小玩具

## 用法

```bash
cat data.txt | ./run.sh
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 为什么写

现有的工具都太重，就想要个能管道拼接的小东西。

## 安装

```bash
git clone https://github.com/USER/cloudmarivelcnpj-notes.git
cd cloudmarivelcnpj-notes
chmod +x run.sh
```
